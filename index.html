🏠 Flutter Architecture Karna MVC

Karna MVC

Arsitektur Flutter yang feature-first dengan typed error handling, data strategy, dan event-driven communication.

Dinamai dari Karna dalam Mahabharata, seorang ksatria yang sempurna dalam dirinya sendiri, tidak membutuhkan apapun dari luar, namun berjuang untuk keseluruhan yang lebih besar. Dalam Bahasa Indonesia: karena. Setiap layer ada karena fiturnya.
Feature-FirstResult<T> DataStrategyEventBus Storage-AgnosticZero Boilerplate

Cara Menggunakan

# Clone repository
git clone https://github.com/AkhmadRamadani/karna-flutter-base.git my_app
cd my_app

# Install dependencies
flutter pub get

# Jalankan contoh
flutter run

# Buat fitur pertamamu
./scripts/create_feature.sh my_feature

# Hapus fitur contoh jika sudah tidak diperlukan
rm -rf lib/features/post test/features/post

Project ini adalah starter template, bukan package. Clone, pelajari contoh fitur post, lalu hapus dan mulai bangun fitur sendiri.

karna_cli New

CLI tool to create and manage Karna MVC Flutter projects.

Install

# Install karna_cli globally via dart pub
dart pub global activate karna_cli

Commands

Create a project

# Create project with default settings
karna create my_app

# Create project with custom organization
karna create my_app --org com.mycompany

Scaffolds a full Karna MVC Flutter project with:

  • Typed error handling (Result<T>)
  • Data strategies (localFirst, staleWhileRevalidate, remoteFirst)
  • Memory management (priority-based service lifecycle)
  • Storage-agnostic caching (Hive, SharedPrefs, InMemory)
  • Event bus for cross-feature communication
  • SnackBar notification service

Create a feature

Run from inside a Karna MVC project:

# Standard feature
karna feature auth

# Feature with memory-aware controller
karna feature feed --memory-aware

Options:

  • --memory-aware / -m — Use MemoryAwareController with automatic memory management

Generates model, repository, data sources, controller, view, and tests. Automatically registers in providers.dart.

Requirements

  • Dart SDK ^3.0.0
  • Flutter SDK (for flutter create and flutter pub add)

Prinsip Utama

🛡
Typed Error Handling

Repository mengembalikan Result<T> (sealed Success/Failure), tidak pernah throw exception.

⚡
Data Strategy

Setiap load call mendeklarasikan strategi: localFirst, staleWhileRevalidate, atau remoteFirst.

🗄
Storage-Agnostic

Interface LocalStorage tunggal sebagai backing semua cache (Hive, SharedPrefs, InMemory).

📡
Connectivity-Aware

Repository memeriksa jaringan sebelum remote call, mengembalikan typed failures saat offline.

🔧
Zero Boilerplate

BaseController mengelola loading/error/refresh state untuk semua controller.

📨
Event-Driven

Typed EventBus mengaktifkan komunikasi lintas-fitur tanpa coupling.

Result<T>

Sealed type yang memaksa error handling eksplisit. Repository tidak pernah throw: selalu mengembalikan Result<T>.

final result = await repository.getUser(id); 
sealed class Result<T> {
  R when<R>({
    required R Function(T data) success,
    required R Function(AppException error) failure,
  });
}
class Success<T> extends Result<T> { final T value; }
class Failure<T> extends Result<T> { final AppException error; }

App Exceptions

Typed exceptions memungkinkan UI bereaksi berbeda untuk setiap jenis kegagalan.

Class Keterangan Field Tambahan
AppException Base class semua exception message, code?
NetworkException Tidak ada koneksi internet –
ServerException 4xx / 5xx dari server statusCode
CacheException Kegagalan local storage –

Data Strategy

Setiap controller mendeklarasikan bagaimana data diselesaikan antara lokal dan remote.

enum DataStrategy {
  /// Cache dulu, network hanya jika miss. Cocok: data jarang berubah.
  localFirst,
  /// Tampilkan cache, refresh dari network di background. Cocok: feeds, dashboard.
  staleWhileRevalidate,
  /// Selalu hit network, fallback ke cache jika gagal. Cocok: data real-time.
  remoteFirst,
}

Matriks Perilaku

Skenario localFirst staleWhileRevalidate remoteFirst
Cache hit, network ok Cache ✓ Cache → Fresh Fresh ✓
Cache hit, network fail Cache ✓ Cache, silent fail Fallback Cache
Cache miss, network ok Fresh ✓ Fresh ✓ Fresh ✓
Cache miss, network fail Error Error Error

BaseController

Semua controller extend class ini. Menyediakan loading/error/refresh state secara otomatis.

abstract class BaseController extends ChangeNotifier {
  bool isLoading;    // true saat initial load
  bool isRefreshing; // true saat background refresh
  bool hasError;
  AppException? error;
  String? errorMessage;

  Future<void> load<T>({
    required DataStrategy strategy,
    required Future<Result<T>> Function() cacheAction,
    required Future<Result<T>> Function() freshAction,
    required void Function(T data) onSuccess,
  });
}

ApiClient

HTTP wrapper tipis yang mengelola auth, retry, dan mapping error.

Fitur Detail
Base URL Dari AppConfig via --dart-define
Auth setAuthToken(token): inject ke semua request
Retry 2x retry dengan backoff untuk transient failure
Error mapping HTTP status → typed AppException
Methods get · post · put · delete

LocalStorage

Interface storage-agnostic. Ganti implementasi di DI, semua fitur mengikuti otomatis.

abstract class LocalStorage {
  Future<Map?> getJson(String key);
  Future<List> getJsonList(String key);
  Future<void> putJson(String key, Map value);
  Future<void> remove(String key);
  Future<void> removeByPrefix(String prefix);
  Future<bool> has(String key);
}
Implementasi Backend Terbaik untuk
InMemoryStorage RAM Dev, tests, prototyping
SharedPrefsStorage SharedPreferences Settings, key-value kecil
HiveStorage Hive Dataset besar, offline-first

EventBus

Sistem notifikasi typed app-wide untuk komunikasi lintas-fitur. Fitur tidak pernah mengimport satu sama lain.

// Publish (dari controller atau repository)
eventBus.fire(UserLoggedOutEvent());

// Subscribe (dalam controller)
_sub = _eventBus.on<UserLoggedOutEvent>().listen((_) => clearProfile());

// Wajib cancel di dispose()
@override
void dispose() { _sub.cancel(); super.dispose(); }

Built-in Events

Event Kapan Difire
UserLoggedInEvent User berhasil login
UserLoggedOutEvent User logout atau session dihapus
SessionExpiredEvent Auth token kedaluwarsa
UserProfileUpdatedEvent Data profil berubah
ConnectivityChangedEvent Status jaringan berubah
CacheClearedEvent Cache app-wide dihapus

Feature: Model

Pure Dart classes. Tidak ada Flutter dependency. Field immutable, memiliki fromJson, toJson, dan copyWith. 

class UserModel {
  final String id, name, email;
  const UserModel({required this.id, required this.name, required this.email});
  factory UserModel.fromJson(Map<String, dynamic> json) =>
    UserModel(id: json['id'], name: json['name'], email: json['email']);
  Map<String, dynamic> toJson() => {'id': id, 'name': name, 'email': email};
}

Feature: Repository

Abstract interface mengembalikan Result<T>. Implementasi mengorkestrasikan local + remote dengan connectivity check.

// Abstract interface
abstract class AuthRepository {
  Future<Result<UserModel>> getUserFromCache(String id);
  Future<Result<UserModel>> getUserFromRemote(String id);
}

// Connectivity check pattern
if (!await _connectivity.hasConnection) {
  return const Failure(NetworkException(message: 'No internet', code: 'NO_CONNECTION'));
}

Feature: Controller

class AuthController extends BaseController {
  final AuthRepository _repository;
  UserModel? get user => _user;

  Future<void> loadUser(String id, {
    DataStrategy strategy = DataStrategy.localFirst,
  }) async => load(
    strategy: strategy,
    cacheAction: () => _repository.getUserFromCache(id),
    freshAction: () => _repository.getUserFromRemote(id),
    onSuccess: (data) => _user = data,
  );
}

Feature: View

Hanya UI logic. Baca state dari controller, panggil methods. Tidak ada business logic di sini.

class UserView extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    final ctrl = context.watch<AuthController>();
    if (ctrl.isLoading) return const CircularProgressIndicator();
    if (ctrl.hasError) return Text(ctrl.errorMessage ?? '');
    return Scaffold(
      appBar: AppBar(
        actions: [
          if (ctrl.isRefreshing) // background refresh indicator
            const CircularProgressIndicator(strokeWidth: 2),
        ],
      ),
    );
  }
}

Dependency Injection

core/di/providers.dart adalah satu-satunya file yang mengimport lintas fitur. Menerima LocalStorage sebagai parameter dari main(). 

List<SingleChildWidget> appProviders({required LocalStorage storage}) => [
  // Core singletons
  Provider<AppConfig>(create: (_) => AppConfig.fromEnvironment()),
  Provider<LocalStorage>(create: (_) => storage),
  // Feature controllers: wiring terjadi di sini
  ChangeNotifierProvider<AuthController>(
    create: (ctx) => AuthController(
      repository: AuthRepositoryImpl(
        remoteSource: AuthRemoteSourceImpl(client: ctx.read<ApiClient>()),
        localSource: AuthLocalSourceImpl(storage: ctx.read<LocalStorage>()),
        connectivity: ctx.read<ConnectivityChecker>(),
      ),
    ),
  ),
];

Testing Strategy

Tests mencerminkan struktur features/ secara persis. Gunakan InMemoryStorage. Tidak perlu Hive atau SharedPrefs. 

// Controller test
test('localFirst menampilkan cached data', () async {
  mockRepo.cacheResult = Success(fakeUser);
  await controller.loadUser('1');
  expect(controller.user, equals(fakeUser));
});

// Repository test
test('failure saat offline dan tanpa cache', () async {
  mockConnectivity.isConnected = false;
  final result = await repository.getUserById('1');
  expect(result.isFailure, isTrue);
});

Menambah Feature Baru

Jalankan generator atau buat manual mengikuti urutan ini:

  • Buat lib/features/<feature>/model/<name>_model.dart
  • Buat repository/<name>_repository.dart (abstract, returns Result<T>)
  • Buat repository/<name>_repository_impl.dart (orchestrate local + connectivity)
  • Buat data_source/<name>_remote_source.dart (gunakan ApiClient)
  • Buat data_source/<name>_local_source.dart (gunakan LocalStorage)
  • Buat controller/<name>_controller.dart (extends BaseController)
  • Buat view/<name>_view.dart
  • Daftarkan controller di core/di/providers.dart
  • Buat test/features/<feature>/: controller, repository, widget tests

Yang TIDAK Boleh Dilakukan

  • Tulis await http.get(...) langsung di controller atau widget. Gunakan ApiClient via remote source
  • Taruh if (userRole == 'admin') di dalam view. Itu milik controller
  • Import dari folder fitur lain
  • Gunakan jaringan nyata atau file system di tests
  • Throw exception dari repository. Kembalikan Failure(...)
